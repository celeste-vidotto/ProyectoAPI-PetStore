PROYECTO API TESTING - PetStore

Este es un proyecto de testing de APIs REST realizado con Postman con el objetivo de poner en practica los conocimientos aprendidos. 
En el mismo utilizamos el siguiente Swagger https://petstore.swagger.io/v2/swagger.json para realizar las pruebas correspondientes 
y asegurar la calidad del mismo. 
Encontrarán: 

- pruebas funcionales,
- validaciones de status codes,
- validaciones de response body,
- generación de reportes con Newman,
- pruebas de performance.
- automatizacion de datos de entrada.

Para los casos de prueba implementados, se organizo el proyecto en dos modulos: "User" y "Login". Dentro de ellos se crearon
pruebas positivas, negativas y de performance. Respecto de estas ultimas se podrá visualizar su evidencia en 
la sección "Pruebas de performance" -> "Evidencia".

Asi mismo, dado las limitaciones de la version gratuita de postman, solo se podrá visualizar los pasos para realizar 
automatizaciones con datos de entrada multiples para una mayor cobertura en los casos de prueba y el archivo con los datos a utilizar en 
la sección "Automatizacion" -> "Pasos para automatizar" -> "Datos-de-entrada-multiples.json"
